# Archive

Historical handoffs + audits relocated here for bounded growth. These docs reference state that's no longer current. Useful for archaeology, not for active work. For current state see `../CHANGELOG.md` + `../superpowers/specs/`.

## Layout

- `handoffs/` — session handoff notes (cross-agent context dumps from prior eras)
- `audits/` — point-in-time audits (skills, paths, alignment) tied to a specific dated snapshot

## Notes

- Versions and paths inside these files may be stale. Don't trust them as canonical.
- Don't link active docs to archive entries — duplicate the still-relevant fact into a current doc instead.
